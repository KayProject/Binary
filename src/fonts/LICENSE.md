# General Sans

Designed by Indian Type Foundry, distributed by Fontshare under the ITF Free Font Licence,
which permits commercial use. Committed here rather than linked, so the site makes no
third-party request to render its own headline and there is no layout shift while a CDN
answers.

Weights here: 400, 500, 600, 700. Roman only. If an italic is ever needed, fetch it from
Fontshare rather than letting the browser synthesise a slant.
